## What I'm building

**Self-hosted AI systems.** I run open-source LLMs (Llama, Qwen, DeepSeek) on llama.cpp and Hugging Face and fine-tune them with LoRA. I'm also building a training pipeline where larger models generate and evaluate the training data used to fine-tune smaller self-hosted ones (synthetic data plus distillation). These models power the AI features in both products below.

**Divinari.** A language-learning platform that brings together language study, cultural heritage, and faith-based learning. It's built with Flutter, Riverpod, and Clean Architecture on an offline-first data layer, with AI-assisted instruction from my self-hosted models plus Gemini.

**OmniScreener.** A crypto analysis and paper-trading research platform. It pulls Coinbase market data and technical indicators, runs ML-assisted analysis, and tracks experiments so I can check how its calls actually turned out.
